# 다크넷 (DARKNET)

트릭컬 리바이브에 나오는 익명 커뮤니티 **다크넷**을 실제로 글을 쓸 수 있게 만든 레딧·디시 스타일 커뮤니티입니다.
디자인은 게임 속 다크넷 화면(분홍 창 테두리, Best/Hot/New 탭, 보상 아이템 타일, 하트 말풍선, 스포일러 보기, 광고 배너)을 따랐고,
메인 화면 배너는 나무위키 다크넷 문서의 `DARKNET` 로고를 썼습니다.

## 실행

Node.js 18 이상만 있으면 됩니다. 설치할 패키지는 없습니다.

```bash
npm start          # 또는 node server.js
```

브라우저에서 http://localhost:3000 을 엽니다. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다.

## 기능

- **글쓰기**: 게시판(일상생활·궁금해요·소설·질문답변·채용공고·홍보), 제목, 본문, 스포일러(선택), 읽는 사람 보상 아이템(선택)
- **익명 닉네임 + 비밀번호**: 디시처럼 가입 없이 닉네임과 비밀번호로 글이나 댓글을 쓰고, 같은 비밀번호로 삭제
- **정렬**: Best(추천−비추천), Hot(시간 대비 반응), New(최신)
- **추천/비추천**: 글과 댓글 모두. 브라우저마다 한 번씩 누를 수 있고, 다시 누르면 취소
- **댓글과 대댓글**: 답글이 달린 댓글은 지우면 "삭제된 댓글입니다"로 남음
- **검색**: 제목, 본문, 닉네임
- **안 읽은 글 표시**: 하트 말풍선. 읽으면 보상 타일이 회색 체크(획득함)로 바뀜
- **보기 방식**: 카드형과 촘촘한 목록형
- 게시판 메뉴(☰), 닉네임 변경(오른쪽 위), 창 최소화(왼쪽 위 ⌄), 모바일 화면 대응

## 구조

```
server.js        HTTP 서버 + JSON API (Node 내장 모듈만 사용)
seed.js          처음 실행할 때 넣는 예시 글
public/          프론트엔드 (index.html, style.css, app.js, assets/)
data/db.json     글과 댓글 저장 파일 (자동 생성, git 제외)
```

비밀번호는 scrypt로 해시해서 저장합니다. 도배 방지를 위해 같은 IP에서는 글을 5초, 댓글을 2초 간격으로만 쓸 수 있습니다.

## 배포

글이 서버에 저장되기 때문에 GitHub Pages 같은 정적 호스팅에서는 동작하지 않습니다.
Render, Railway, Fly.io 같은 Node 호스팅이나 VPS에서 `npm start`로 실행하세요.
`data/` 폴더는 영구 디스크에 두어야 재시작해도 글이 남습니다(`DATA_DIR` 환경 변수로 위치 지정).
